# Soi Mặt Bằng — Saigonesee

Web app (một file `index.html`) thẩm định mặt bằng mở chi nhánh Saigonesee: nhập địa chỉ + bán kính → dân số, thu nhập, quán đối thủ, doanh thu ước tính, tiền thuê, hoà vốn, SWOT. Mọi con số có nguồn (chạm vào số để xem link).

**Mở:** https://saigoneseecoffee.github.io/locationcheck/ (iPhone: Safari → Chia sẻ → Thêm vào MH chính).

**Dữ liệu trực tiếp:** U.S. Census (ACS 2020–2024, Điều tra 2020, CBP, TIGERweb), OpenStreetMap (Overpass, Nominatim), MBTA V3.
Cần Census API key miễn phí: https://api.census.gov/data/key_signup.html → dán vào Cài đặt (key chỉ lưu trên máy).

**Hiệu chỉnh:** phân tích tiệm 39 Trotter Rd, nhập doanh thu thật/tháng trong Cài đặt → “Tiệm chuẩn”.

Mô hình chỉ để sàng lọc ban đầu, không thay thế khảo sát thực địa.
